# Contributing

Thank you for helping improve the Product Weaver plugin.

## How this repository works

This repository is published automatically. Each release of the plugin is
copied here from a private repository where development happens, as one
commit per release. Nobody edits the files here by hand.

## Issues are welcome

Open an issue for a bug, a question or an idea. For a bug, please include:

- the assistant and version you use (for example Claude Code 2.1.306),
- what you asked, what you expected and what happened,
- any error message, with names and quotes from interviews removed.

To report a security problem, follow [SECURITY.md](SECURITY.md) instead.

## Pull requests

We read every pull request, but we cannot merge one here: the next release
would replace the files. If we take your change, we make it in the
development repository, release it, and close your pull request with a note.
An issue that describes the change is often the quicker way.
